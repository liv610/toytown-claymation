# Toy Town — Claymation Street Corner (proof of concept)

A standalone visual experiment for *Railroad of Hope* (Toys for Tots): can a
small, genuinely beautiful, navigable claymation world be built with free,
open-source tools?  This repository is independent of any other project.

## Status

## Reproduce

Everything — every object, material, light and the camera — is generated by
Python.  No paid assets, no external asset downloads.

```bash
./tools/install_blender.sh            # Blender 4.5.3 LTS (GPL), official build
# quick preview (800x450, ~2-3 min on 4 CPU cores)
blender -b --factory-startup --python scripts/build_scene.py -- --preview --render renders/preview.png
# final still (2560x1440, 128 samples + OpenImageDenoise; ~90 min on 4 CPU cores, much faster on a GPU)
blender -b --factory-startup --python scripts/build_scene.py -- --res 2560x1440 --samples 128 \
        --render renders/stage1/toytown_stage1_hero.png
```

Each run also writes `blender/toytown_stage1.blend`, which opens in the Blender UI
for hand-tweaking (pass `--no-save` to skip). The script is deterministic (seeded RNG).
Other flags: `--border x0,x1,y0,y1` renders a crop region for checking material detail.

## Layout

```
scripts/build_scene.py   entry point: assembles the scene, camera, render settings
scripts/tt/lib.py        clay geometry helpers + hand-made shaders (clay, snow, glow, fabric, wood)
scripts/tt/palette.py    Toy Town palette (sRGB -> linear)
scripts/tt/buildings.py  blue toy shop, pink cottage, background house generator
scripts/tt/street.py     ground heightfield, domed cobblestones, snowbanks
scripts/tt/trees.py      evergreens from drooping pinched-clay tiers
scripts/tt/props.py      lampposts, bench, wagon, presents, stone viaduct, hills
scripts/tt/world.py      sky, studio lighting, camera/DOF, falling snow, compositor
renders/stage1/          delivered renders
docs/ARTISTIC_NOTES.md   decisions, honest assessment, next steps
docs/iterations/         selected iteration frames (what was wrong, what changed)
tools/install_blender.sh pinned Blender install
```
